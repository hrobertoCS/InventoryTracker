<h1 align = "center">InventoryTracker</h1>
<h2 align = "center">Inventory management app</h2>
<h3 align = "center">Built using Java, Android Studio, and SQLite</h3>
<h2 >Features:</h2>

- Register account/login
- Add/delete items and update their quantities
- Optional low stock alerts through SMS
- View inventory items in a grid
